# Installation d'une IDE
Afin de coder efficacement en C++ (et en tout autre langage de programmation) il est crucial d'utiliser un **environnement de dévelopement** (IDE). Celui-ci fonctionne comme une boîte d'outil qui nous sert à programmer plus efficacement, notamment au niveau de la coloration syntaxique et du débogage. Dépendamment de votre système d'exploitation de différentes IDE sont disponibles. Ce tutoriel supposera une installation de Windows pour pouvoir installer MS Visual Studio; pour les utilisateurs de Linux je recommende CLion, Vs Code ou même Neovim.

## L'installeur
Veuillez vous dirigez vers [ce lien](https://visualstudio.microsoft.com/) pour télécharger la version la plus récente de Visual Studio.

Suivez les options de l'installateur et sélectionez toutes les options qui concernent le C++.
